# Start here

1. Unzip this folder somewhere easy to find, like Documents/rezflo-video-studio.
2. Open a terminal in that folder and type `claude`.
3. First time only: open prompts.md, copy PROMPT 01 (Setup), paste it into Claude Code, and let it install what's missing. Then close Claude Code and open it again.
4. /brag is already in this repo (`.claude/skills/brag`), so it works as soon as you open Claude Code here, including cloud sessions. No plugin install needed.
5. Test that everything works by pasting:
   Render the opener in opener/ to renders/opener-test.mp4 and tell me where it is.

Claude Code reads CLAUDE.md automatically, so it already knows about RezFlo, the brand, and the prompts. Just say what you want.
